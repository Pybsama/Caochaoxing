# 爱丽丝读绘本图标

三端使用《BLACK SOULS II》中爱丽丝捧着绘本的画面。图标将截图转为灰度，收平了嘴角，并围绕脸和书裁成满版方形。公开使用这张游戏画面的授权待确认。[游戏截图](https://fgguides.com/wp-content/uploads/2024/10/Daughter-Alice.png) · [素材归属](../../THIRD_PARTY_NOTICES.md#图标及其他素材)

定稿是 480 × 480 的灰度 PNG。在 Mac 上从仓库根目录运行 `swift docs/artwork/render-icon.swift`，可导出 iOS 的 1024 像素不透明图标、macOS Dock 图标以及 Android 自适应图标。Android 的主题图标按画面明暗生成透明蒙版，由启动器着色。[图标定稿](Avatar.png)
